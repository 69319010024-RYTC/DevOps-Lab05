# DevOps-Lav05: Jigsaw Puzzle

เกมจิ๊กซอว์สำหรับเล่นผ่านเว็บเบราว์เซอร์ สร้างด้วย HTML, CSS และ JavaScript โดยใช้ภาพ `core.jpg` แบ่งเป็น 20 ชิ้น

## วิธีเล่น

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ จากนั้นลากชิ้นส่วนไปวางบนกระดาน เมื่อวางใกล้ตำแหน่งที่ถูกต้อง ชิ้นส่วนจะดูดเข้าที่

- กด **แสดงภาพใบ้** เพื่อเปิดภาพอ้างอิงบนกระดาน
- กด **เริ่มใหม่** เพื่อสุ่มชิ้นส่วนและเริ่มเกมอีกครั้ง
- กด **เปิดเสียง** เพื่อเปิดเสียงคลิกตอนหยิบ/วางชิ้นส่วน และเสียงดนตรีบรรเลงเบา ๆ ระหว่างเล่น
- ใช้เมาส์หรือหน้าจอสัมผัสในการลากชิ้นส่วน
- บนหน้าจอคอมพิวเตอร์ ชิ้นส่วนจะจัดไว้รอบกระดานทั้งหมด ส่วนหน้าจอมือถือจะแสดงชิ้นส่วนใต้กระดานเพื่อให้ชิ้นใหญ่พอสำหรับแตะ
